# 技术分析大师统一 Beta 工作记录

日期：2026-08-03

## 今天完成了什么

保留原有“图表分析”和知识库，在同一套首页中加入“均线无忧”“指标大师”“缠中说禅”三个可点击工具。四个入口使用统一的白底卡片、浅色线条图标和一致的页面层级，不再把旧首页和新功能简单堆叠。

“均线无忧”已经接入真实行情计算。用户可以选择 1、2、3、5、10 年，查看单均线、双均线、长期安全区、中轴线和乖离率历史分位。长期线从 200 个交易日以上的候选中筛选；如果没有满足恢复能力和稳定性要求的线，页面会明确说明不具备“便宜线/无忧线”条件。

“指标大师”第一版包含 MACD、KDJ、RSI、SuperTrend 和信息离散度。前四项做参数搜索与历史表现比较；信息离散度只解释价格变化是集中爆发还是分散运行，不给买卖信号。

“缠中说禅”完成独立 Beta 页面与后端。当前提供包含处理、拐点、笔、中枢和候选信号，并清楚标注理论来源和版本边界，不冒充完整原著实现。

原有图表分析的规则检测和 FAE 客观裁决流程保持不变，`pattern_core_v7.py` 没有修改。本轮还修复了后端启动时项目根目录未进入 Python 搜索路径的问题，避免云端导入 `fae` 失败。

## 已验证

所有小程序 JavaScript 均通过语法检查，JSON、WXML 标签和页面路由完整。三个新模块均通过合成行情测试；上证指数真实行情下，均线、信息离散度和缠论 Beta 接口均返回完整结果。
